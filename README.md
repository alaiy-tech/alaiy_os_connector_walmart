# Alaiy Os Connector Walmart

Walmart Marketplace connector for AlaiyOS — listings, orders, and sales as
whitelisted tool calls for Ask Alaiy, following the same shared row shape as
the Amazon connector.

### Installation

```bash
bench get-app alaiy_os_connector_walmart
bench --site <site> install-app alaiy_os_connector_walmart
```
